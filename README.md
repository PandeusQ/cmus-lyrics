# cmus-lyrics

Lightweight lyrics fetcher for cmus written in Rust.

## 📦 Installation

### Quick Install (Recommended)
Install directly from GitHub via Cargo:
```bash
cargo install --git https://github.com/PandeusQ/cmus-lyrics.git
```

### or 


### 1. Prerequisites
Ensure you have Rust and Cargo installed.

### 2. Clone the repository
```bash
git clone https://github.com/PandeusQ/cmus-lyrics.git
cd cmus-lyrics
```

### 3.Build from source
```
cargo build --release
```
### 4. Install globally
cargo install --path .

### 5. Run
The compiled binary will be placed in `target/release/`:
```bash
./target/release/cmus-lyrics
```
### or
```
cmus-lyrics-rs
```
